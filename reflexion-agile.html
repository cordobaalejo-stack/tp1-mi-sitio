# a ¿Qué diferencia hay entre Scrum y Kanban? Scrum y Kanban son meodologias agiles, pero se diferencian en su forma de organizar el trabajo scrum es mas estructurado y divide las tareas en periodos fijos llamados sprints, con roles definidos y una planidicacion previa donde no se suelen hacer cambios hasta finalizar el ciclo. en cambio Kanban es mas flexible, no tiene tiempo fijo ni roles obligatorios y permite gestionar el trabajo de forma continua usando un tablero visual donde las tareas se mueven según su progreso. # ¿Cuál te parece más útil para un proyecto individual y por qué? para un trabajo individual conviene usar el kanba ya es mas flexible a la hora de trabajras solo y permite adaptar las a tareas a nosoros por decirlo de alguna manera # b ¿Qué es un MVP (Producto Mínimo Viable) y cómo lo aplicarías si te piden hacer un sitio web para un negocio local? la idea del mvp es crear un sitio con las cosas mas necesarias y basicas sin agregar cosas demas y ya asi poder usarlo yo lo aplicaria de manera rapida haciendole unas preguntas al cliente sobre que seria y que quiere que tenga la web de manera que la entrega sea rapida y al cliente le guste # c ¿Cómo te ayudó el tablero Kanban a organizar las tareas de este TP?
