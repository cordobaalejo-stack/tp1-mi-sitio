## Comando usados ##
# 1- pwd 
**Funcion** : Muestra la ruta de la carpeta actual en la que estás
*situacion*: Lo use para situarme en la carpeta correcta antes de crear los archivos 
# 2- ls 
**Funcion** : Lista los archivos y carpetas dentro del directorio actual
*situacion*: me sirvio para ver los archivos creados dentro de la carpeta
# 3- cd
**Funcion** : Sirve para navegar de carpeta en carpeta con este comando
*situacion*: Me sirvio para entrar a la carpeta e interactuar con mis archivos
# 4- touch
**Funcion** : Crea un archivo vacío
*situacion*: Lo use al momento de crear los 2 archivos del trabajo
# 5- mkdir 
**Funcion** : Crea una carpeta nueva
*situacion*: Para crear la carpeta donde puse los 2 archivos
# 6- wich
**Funcion** : Sirve para saber dónde está ubicado un comando en tu sistema
*situacion*: Revise donde estaba instalado git
# 7- cat
**Funcion** : Sirve para mostrar el contenido de un archivo
*situacion*: Visualize lo que habia en index.html
# 8- code 
**Funcion** : sirve para abrir Visual Studio Code desde la terminal
*situacion*: Lo utilize para abrir la carpeta de mi proyecto
# 9- clear
**Funcion** : Sirve para limpiar la pantalla de la terminal
*situacion*: Me sirvio para cuando termine de poner mis datos y limpiar la terminal y segui con lo otro
# 10- git config --global user.name
**Funcion**: Sirve para configurar tu nombre en Git, el que va a aparecer en los commits que hagas
*situacion* : Lo use para configurar mi git apenas lo instale
